# Scripted browser metrics v1

`apps/clinician-web/e2e/scripted-metrics.spec.ts` exercises local access-key entry, keyboard activation of the workspace, and opening the synthetic example. It records browser click events, keydown steps, Navigation Timing load duration, script wall time, uncaught page errors, failed requests, HTTP resource errors, and whether the target workspace was reached. The attached JSON run is the measurement source of truth for that run.

Measurements are generated by Playwright in a local-only synthetic fixture. They describe one automated workspace-opening script, not clinician behavior or clinical task performance. Load latency is a single-run observation, not a controlled benchmark. The `requestfailed` and HTTP resource lists are kept separate from uncaught interaction errors so a product fallback can be distinguished from a failed task. No cost or clinical accuracy is inferred.
