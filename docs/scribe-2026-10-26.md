# Scribe workflow and evaluation delivery — 2026-10-26

Public local models only; no paid inference or gated model terms. The workspace remains synthetic-only. Engineering controls are implemented; ASR qualification and independent clinical acceptance are not established.

## Encounter review

The note workspace now keeps audio playback, a SOAP preview, the saved transcript and source citations together. Citation links seek to the containing original-timeline interval and highlight its source turn; they do not imply word alignment. Severity groups put critical warnings first and link back to affected statements. Editing clinical content clears review attestations. An approved note whose source has changed loads its exact historical transcript/audio, labels historical verification and approval, and retains the original approved version and exports.

Optional Qwen extraction retains omitted source spans through an explicitly labelled deterministic fallback. Every proposal remains unreviewed and evidence-linked; model omissions remain visible. Source-span retention does not prove that every statement is clinically complete or semantically atomic. Complex conjunctions, attribution and relations still require clinician splitting/correction. Oversized requests fail rather than silently truncate.

Drafting requests one cited fact per statement and flags merged/duplicate citations, omissions, changed sections and paraphrases. Each saved proposal includes the deterministic baseline from the same input facts. The interface shows the configured local model beside that baseline. Neither extraction nor drafting writes an approved note. The independent Qwen verifier remains advisory and cannot clear deterministic findings or approve a note.

## Recording and interruptions

Browser dictation supports **30 minutes or 64 MiB**, replacing the five-minute limit. A disconnected microphone retains a partial recording for review, local download or explicit retry. Retries reuse upload identity, and navigation is guarded while capture/upload/retry is pending. Live capture remains in browser memory: keep the tab open. This is stop-to-transcript capture, not word-by-word streaming.

Two [real-worker stress runs](../evaluation/reports/long-recording-real-worker-2026-10-26.json) processed 20- and 30-minute files through authenticated upload, ingestion, the installed `tiny-en-smoke-v1` recognizer and immutable transcript publication. Both preserved duration/hash, produced valid bounded timestamps and created no note or approval automatically. Observed wall times were 67.99s and 110.10s under concurrent local benchmark load. The files repeat one licensed public utterance with digital silence; they are software stress signals, not full clinical encounters, representative latency tests or independent ASR accuracy evidence. Their WER was 17.65%; the development recognizer remains unqualified.

## ASR-101 — full conversation

The [full comparison](../evaluation/reports/conversation-comparison-2026-10-26.md) includes per-consultation, per-role and literal clinical-term counts, raw hypotheses and every failure. All conditions used the unchanged three-consultation source and all 5,204 reference words.

| Condition | Aggregate normalized WER |
| --- | ---: |
| Original mixed fixed-30s baseline | 13.05% |
| Mixed overlap | 14.76% |
| Mixed energy-selected boundaries | 14.34% |
| Original separate-channel condition, including two failed case/role runs | 40.30% |
| Post-hoc filler-tolerant overlap | 14.62% |
| Post-hoc filler-tolerant energy boundaries | 14.10% |
| Separate-channel empty-output reconstruction | 14.89% |

Six failures reproduced as the wrapper rejecting native empty strings. A tested **opt-in** adapter accepts only that exact empty-output condition; other native errors still propagate. The separate reconstruction retains original failed evidence, empty-window omissions and every reference word. It is not a fresh full rerun. Legacy defaults and the original eight-candidate clip ranking remain unchanged.

The best aggregate remains the original baseline; no tested alternative achieved the requested improvement over it. Native-empty handling improves operational classification, but does not establish better lexical accuracy. The initial reporting-key interruption and its hash-bound resume are preserved. All original input windows remain covered. Window bounds and reference-turn bounds are never represented as ASR word timestamps. **The 5% gate remains unmet, and no qualifying timestamped candidate was integrated or promoted.** The existing worker still supports the explicitly unqualified timestamped development recognizer.

Baseline error diagnostics counted 385 deletions, 220 substitutions and 74 insertions. Of 679 edits, 357 fall in uncertain-reference turns and 545 in turns overlapping another reference role; these categories overlap and do not establish causality. Reference-role attribution of insertions is diagnostic and uses the preceding reference word. Literal term counts do not replace independently adjudicated clinical concept metrics.

## DIA-102 — speaker turns

The [speaker comparison](../evaluation/reports/speaker-comparison-2026-10-26.json) uses separate scoring code against the same upstream turn labels. The fixed-window baseline scored **50.91% weighted DER**; separate-channel Silero speech detection scored **24.81%**, a reduction of 26.10 percentage points. Per-role missed/extra/correct durations and one-to-one turn-boundary matching at 250ms tolerance are retained.

This is a different recording modality and a development result. Optimal reference mapping is a scoring operation, not an application role assignment. Synchronized separate channels, cross-talk/channel-swap checks and clinician-confirmed roles are still required. Independent human adjudication and a clinically approved speaker-error tolerance are unavailable. The application retains unknown-role/manual-review fallback; it does not claim that the new benchmark makes single-microphone diarization reliable. The two-channel path is a benchmark alternative, not new browser stereo capture or a production diarization implementation.

The Qwen counts include two omission misses and two timeout/non-verdict cases across the two cohorts. Combined recommendations flag rule alerts, non-supported model verdicts or model failure for human review. They are not clinical approval decisions. The harder cohort demonstrates that bag-of-words rules miss relationships and reject valid paraphrases. No clinical sensitivity, specificity, calibrated safety or independent gold is claimed.

The [local drafting comparison](../evaluation/reports/scribe-drafting-comparison-2026-10-26.json) preserved reviewed facts exactly in **3/4** Qwen 1.5B cases and **4/4** deterministic cases. All four model calls were admitted; altered content was flagged. These are small synthetic development fixtures, not evidence that model drafting is clinically equivalent to templates.

## Validation and reproduction

The final full backend/worker suite passed **187 tests, one local PostgreSQL skip**, including 20 focused scribe regression cases. The frontend production build passed. All nine browser end-to-end tests passed; the extended historical-source/severity-navigation workflow passed again after its additions. These tests use fake microphone input and synthetic/public fixtures. A simulated clock verifies the 30-minute capture control; the real-worker files independently test actual 20/30-minute media duration. Local screenshots were inspected at desktop and mobile widths.

Normal hosted CI tests the API, optional ASR dependencies, PostgreSQL, frontend and container build. The heavyweight local model/browser evaluations use already provisioned models/fixtures; no self-hosted runner registration or independent clinical review is implied by CI success.

Reproduction entry points:

- `services.conversation_experiment --out NEW_PATH` and `--resume-from PATH` for the pinned full-audio ablation.
- `services.conversation_errors --experiment REPORT --out NEW_PATH` for exact lexical edit diagnostics.
- `services.omi_failure_probe --experiment REPORT --out NEW_PATH`, then `services.omi_empty_reconstruction --experiment REPORT --probe PROBE --out NEW_PATH` for the opt-in runtime analysis.
- `services.overlap_reassembly --experiment REPORT --out NEW_PATH` for the explicitly post-hoc stitch ablation.
- `services.channel_diarization --out NEW_PATH` and `services.speaker_comparison --out NEW_PATH` for channel/turn evidence.

- `services.local_drafting_evaluation --models qwen2.5:1.5b --structured --output NEW_PATH` for template/model comparison.
- `services.long_recording_smoke --out NEW_PATH` against an isolated synthetic application/worker on port 8003 with the existing public clip and local development ASR provisioned.
