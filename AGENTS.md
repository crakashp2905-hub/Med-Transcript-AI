# Instructions for AI coding agents

Read [the agent workflow](docs/ai-agent-workflow.md) before editing this repository. Work from the repository root, use only already available local tools/data, and keep claims tied to the exact source commit and saved evidence.

Never fetch assets, install packages, use paid/hosted APIs, run inference on the reserved acceptance cohort, or modify protected acceptance material. Do not overwrite benchmark inputs or historical reports. Use a new versioned path for every new evaluation output. Stage only task-specific files; preserve pre-existing working-tree changes.

Real-patient processing, clinical approval, and deployment are not authorized by passing tests or by this file.
